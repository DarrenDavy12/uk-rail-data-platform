         
           
# UK Rail Data Platform — Architecture

```
             UK Rail Public API
                     │
                     ▼
                Python ETL
          Extract → Transform → Validate
                     │
                     ▼
              Bronze Parquet
                     │
                     ▼
                  AWS S3
                     │
                     ▼
                 Snowpipe
                     │
                     ▼
              Snowflake RAW
                     │
                     ▼
              Snowflake Stream
                     │
                     ▼
          Snowflake Task (conditional)
          WHEN stream has pending data
                     │
                     ▼
          Snowpark Python Procedure
                     │
                     ▼
             Snowflake SILVER
                     │
                     ▼
                    dbt
             Transform and test
                     │
                     ▼
             Snowflake GOLD
                     │
                     ▼
         Analytics / BI consumption
              (e.g. Power BI)
```
